# blender-tachie

Blender 用の立ち絵アドオンです。VOICEVOX の音声に合わせて口パク・まばたきする立ち絵と字幕を、
Video Sequencer に並べます。YMM4 の「動く立ち絵」「シンプル立ち絵」「PSD 立ち絵」の素材と、表情プリセットも読み込めます。

## できること

### セリフを置く
- セリフを入力すると、音声と字幕を再生位置に置く（YMM4 と同じく、立ち絵はセリフとは別に置く）
- 「立ち絵だけを置く」で立ち絵を置く。まばたきし、重なっているそのキャラクターのセリフの間だけ口パクする。
  セリフの表情（指定したパーツ）はそのセリフの間だけ立ち絵に重なる。セリフを動かす・作り直す、立ち絵を伸ばすと自動で描き直す
- 立ち絵ごとに表情・パーツ（「パーツ（この立ち絵だけ）」、YMM4 の「表情: カスタム」）・左右反転・不透明度・回転角・
  フェードイン／アウト・喋る時のみ表示を変えられる（立ち絵を選んでプロパティの「ストリップ」タブで。PSD 立ち絵はパーツを変えられない）
- 台本（1 行に `キャラ名: セリフ`、表情は `キャラ名(困り): セリフ`）を一括で流し込む。
  YMM4 の台本（`キャラ名「セリフ」`、CSV・TSV の `キャラ名,セリフ`。UTF-8 か Shift_JIS）も読める
- セリフの修正と再生成。長さが変わったら後ろのストリップをずらす。「字幕だけ変える」なら音声を作り直さずに字幕のテキストだけ直す
- 複数のセリフを選んで、表情・声・音量などをまとめて変える
- セリフは時間を重ねて置ける（同時に喋る）。音声・字幕・キャラ名はそれぞれのキャラクターのチャンネルに置く
- セリフの形は「音声と字幕」「音声だけ」。キャラクターごとの既定値と、置いたセリフごと（パネル・まとめて変える）に選べる
- 立ち絵の無いキャラクター（ナレーションなど、声と字幕だけ）も追加できる（キャラクター設定のメニュー）。
  声・字幕の設定はキャラ名で初期値として保存でき、同じ名前で追加するとその設定で始まる

### 表情
- キャラクターごとの基本の表情と表情プリセット。他・後（腕や記号）はスロットごとに置き換える（YMM4 と同じ）
- 表情プリセットは YMM4 と同じく、選んだときにパーツがそれになるもの。そのあとパーツを 1 つずつ変えられる
  （立ち絵・セリフ・表情ストリップを選んで「パーツ（この〇〇だけ）」で）。後でプリセットを編集しても、置いたものは変わらない
- セリフ・表情ストリップの表情は、指定したパーツだけを重なる立ち絵の上に重ねる（何も指定しなければ立ち絵のまま。
  「基本の表情」を選ぶと、立ち絵で変えたパーツも打ち消す）
- 表情ストリップ: タイムラインに置いた範囲だけ表情を変える。セリフの途中からでも、音声はそのまま
  （動かしたり伸ばしたりすると自動で描き直す）
- セリフの表情を表情ストリップにする: 選んだセリフの表情で、セリフの区間に表情ストリップを置く（セリフの表情はそのまま。
  見た目は同じで、表情ストリップを伸ばしてセリフの前後も同じ表情にできる。セリフの区間はセリフの表情が残るので、縮めたり動かしたりしても
  その区間はセリフの表情のまま。表情ストリップや同じキャラの別のセリフが重なるセリフ、ミュートしたセリフには置かない）
- AI で表情を割り当てる: 選んだセリフのテキストを LLM（OpenAI 互換のチャット API）に送り、キャラの表情プリセットから
  合うものを選ばせる（[ymm4faceassign](https://github.com/cathandnya/ymm4faceassign) と同じ仕組み）。下の「AI で表情を割り当てる」を参照
- パーツ・表情を選ぶ一覧、表情の欄、表情プリセットの一覧に見本を出す（パーツはそのパーツだけ、表情は合成した立ち絵の顔のまわりを
  切り抜いたもの。背景は白）

### 立ち絵の動き
- 喋っている間に跳ねる（上下）・揺れる（左右に傾く）。高さ・角度・速さはキャラクターごと
- 登場・退場（フェード、近い方の画面の端からスライド）。キャラの立ち絵が現れる・消えるところに自動で付く
- 立ち絵ごとの位置・大きさ（足元を中心に拡大）
- 置いてある立ち絵にすぐ反映する（立ち絵ストリップの位置・回転・不透明度のキーフレーム）
- 立ち絵ストリップの位置・大きさ・回転・不透明度はアドオンが管理するので、パネルで変える
  （Blender のストリップ設定で直接変えても、セリフの追加などで元に戻る）

### 声（YMM4 のボイスアイテム相当）
- キャラクターごとに声のエンジンを選べる（VOICEVOX と同じ API の AivisSpeech・SHAREVOX・COEIROINK v1、または URL を指定）
- セリフごとにキャラクター・スタイル・読み上げ速度・声の高さ・抑揚・合成の音量・開始/終了無音・間の長さを変える
- 発音（読み・アクセント）の編集と試聴。ストリップタブに折り返して出し、押すと「発音を編集」のダイアログで書き換える。
  台本では `セリフ{キョ'ウワ/イ'イ/テ'ンキ}`
- 抑揚の編集（YMM4 の「抑揚を編集」と同じ並び）: アクセント句を横に並べ、モーラごとの音高・母音の長さを縦の棒で、子音の長さ・
  句全体の高さを数値で変える。アクセントの位置はモーラの上のボタン、句の分割はモーラの文字、結合は句の間の鎖のボタン。試聴できる
- VOICEVOX のユーザー辞書の登録・削除
- 音量・パン（すぐ反映）、フェードイン/アウト・セリフ後の余韻

### 口パク・字幕
- 口パクはあいうえお式（音素の母音）と音量式
- 字幕のフォント・大きさ・折り返し幅（px。0 なら画面の幅の 80%）・色・縁取り・行間・高さ・背景の帯（色・余白・角の丸み）は
  キャラクターごと。変えると置いてある字幕にすぐ反映する
- 字幕の上にキャラ名（縁取りの色の帯）を出す、字幕のフェードイン
- セリフごとに字幕の文字の大きさ・折り返し幅を変えられる（ストリップタブ。0 ならキャラの設定）
- セリフごとに字幕（とキャラ名）の位置をずらせる（同時に喋るセリフの字幕が重なるときなど。重なると置いたときに知らせる）。
  プレビューで字幕やキャラ名をつかんで動かしてもよい（動かした位置はストリップタブの字幕の位置に入り、再生成しても残る）
- 見出しテロップ（話題の切り替えに出す大きめの文字。スタイルはシーンで共通で、変えるとすぐ反映）
- 立ち位置・左右反転もキャラクターごとで、すぐ反映する。左右反転は立ち絵ごとにも変えられる（選択中の立ち絵の「左右反転」）
- 「書き出し」パネル: 動画の書き出し設定のプリセット（1080p / 60fps / 720p / 4K / 縦長、MP4・H.264・AAC）、
  字幕を SRT / WebVTT で書き出す（YouTube などの字幕用）

### チャンネル
- アドオンが置くストリップは、キャラクター × 役割ごとに 1 本ずつのチャンネルに並べる。下から 音声 → 立ち絵・表情 → 字幕 →
  キャラ名 → 見出し で、どのキャラクターの字幕も全員の立ち絵より手前に出る。チャンネルには「ずんだもん 立ち絵」のような名前を付ける
- 既定は 10 番から上を使い、1〜9 番は動画・背景・効果音・BGM の場所として空けておく（「チャンネル」パネルの
  「いちばん下のチャンネル」で変えられる）。キャラクター一覧の順が立ち絵の重なり順で、並べ替えるとチャンネルも並べ直す
- 手で別のチャンネルに動かしたストリップは、並べ直し・再生成でもそのチャンネルに残す。「チャンネルを整理する」で全部を元の並びに戻す
- チャンネルのミュート・ロックは、並べ直しても同じ役割のチャンネルについてくる

### BGM
- 選んだ音声ストリップを BGM にすると、セリフの音声が鳴っている間だけ自動で音量を下げる（ダッキング）。
  下げる割合と、下げる・戻す時間を選べる。セリフを追加・移動すると作り直す
- BGM の音量はアドオンが管理するので（音量のキーフレーム）、「BGM」パネルで変える

### 効果音
- よく使う効果音を登録しておき（アドオン設定、全 .blend 共通。音量も登録できる）、「効果音」パネルのボタンで置く
- 置く場所は再生位置か、選んでいるセリフそれぞれの頭

### テンプレート
- 選んだストリップ（セリフ・立ち絵・表情・画像・動画・音声・テキスト・カラー）を名前を付けて登録し、「テンプレート」パネルのボタンで
  再生位置に置く（YMM4 のテンプレートと同じ使い方）。アドオン設定に保存するので、どの .blend でも使える
- セリフは置くときに合成し直す（キャラ・テキスト・表情・声・発音・抑揚・形を持つ）。キャラは名前で探す
- 立ち絵は表情・パーツ・位置・大きさ・左右反転・不透明度などの立ち絵ごとの設定ごと置く（同じキャラの立ち絵に重なるときは置かない）
- 「立ち絵より奥に置く」にしたテンプレート（背景など）は、画像・動画・カラーをアドオンのチャンネルより下に置く
- YMM4 のテンプレート（`user/setting/<版>/YukkuriMovieMaker.Settings.ItemSettings.json`）を読み込める。
  ボイス・立ち絵アイテム・表情・画像・動画・音声・テキストを取り込み、トランジション・図形・エフェクトは読まない

### YMM4 のプロジェクトの読み込み
- 「台本の流し込み」パネルの「YMM4 のプロジェクトを読み込む」で、.ymmp のキャラクター・セリフ・表情を読み込む
  - セリフの音声は .ymmp に保存された YMM4 の音声を使う。無ければ YMM4 に保存された発音・抑揚・話速などで VOICEVOX から合成し直す
    （同じ位置に置く。Windows（ARM）版は YMM4 の音声を展開する Brotli が無いので、いつも合成し直す）。
    合成はバックグラウンドで進み、ステータスバーに進み具合が出る。Esc でやめられる（置いたセリフは残る）
  - 無いキャラクターは素材フォルダを探して追加し、声・字幕・立ち位置・左右反転・基本の表情を写す。基本の表情と位置は、
    いちばん長く出ている立ち絵アイテムから取る
  - YMM4 で立ち絵の無いキャラクターは、立ち絵の無いキャラクターとして追加し、セリフは音声と字幕（字幕を出さないなら音声だけ）で置く
  - ボイスアイテムの表情はセリフのパーツに、表情アイテムは表情ストリップにする（表情プリセットは作らない）
  - ボイスごとに設定した字幕の位置は、セリフごとの字幕の位置に写す
  - 立ち絵アイテムはその区間の立ち絵として置く（重なるセリフの間だけ口パクする）。立ち絵アイテムの表情・位置・大きさ・
    左右反転・不透明度・回転角・フェードイン／アウト・喋る時のみ表示は立ち絵ごとの設定にする（合成モード・Z などは読み込み結果に出す）
- 素材フォルダと画像・動画などのファイルは、YMM4 の元のパスの後ろの部分を、.ymmp のフォルダとその上 3 階層から探す
  （Windows と同じフォルダの並びで持ってくれば、指定しなくても見つかる）。見つからないものがあれば、「台本の流し込み」パネルに
  確認の欄が出るので、キャラクターごとの素材フォルダや探す場所を指定してから「読み込む」
- 画像・動画・音声・テキストのアイテムも、位置・大きさ・回転・不透明度・音量・再生速度・切り取り位置・直線移動の
  アニメーションごと置く（ダイアログで切れる）
  - 立ち絵より奥のレイヤーの画像・動画は、アドオンのチャンネルより下に置く（足りなければアドオンのチャンネルを上へずらす）
  - 動画は素材のフレームレートと再生速度に合わせるため、スピードコントロールのストリップを重ねることがある
  - BGM はアドオンの BGM（ダッキング）にはしない（YMM4 の音量のまま。使うなら「BGM にする」）
  - 写せる映像エフェクト: テキストの背景塗りつぶし（単色）、画面外から移動して登場・退場、画像の縁取り（単色）、
    モザイク（エフェクトアイテムの四角い範囲）、行間、立ち絵アイテムの跳ねながら登場退場（YMM4 と完全には同じ動きでない）
  - トランジションアイテムはフェードとプッシュを写す（前の場面の最後のコマから切り替える）
- 図形のアイテム、上に挙げていない映像エフェクト（影・ぼかしなど）、フェード・プッシュ以外のトランジションは読み込まない。
  読み込まなかったもの・見つからなかったファイル・写せなかった設定は、テキストエディタの「YMM4 の読み込み結果」にまとめる
- YMM4 の音量 50 を等倍として写す

### コマンドライン
- 立ち絵の合成と口パクの計算は Blender に依存しない Python モジュールで、台本から wav と透明連番画像を書き出せる

## 使い方

1. Video Sequencer のサイドバー（N キー）の「立ち絵」タブを開く
2. ＋ で素材フォルダ（PSD 立ち絵なら PSD ファイル）を選んでキャラクターを追加し、キャラクター設定で話者（VOICEVOX のスタイル）や表情を選ぶ
3. 「立ち絵だけを置く」で、キャラクターを出しておきたい区間に立ち絵を置く（長さは右の秒数。あとで伸ばせる）
4. 「〇〇のセリフを追加」を押して開くダイアログでセリフを入力する、または「台本の流し込み」でまとめて置く（重なる立ち絵が口パクする）。
   字幕の改行は `\n`（¥n）と書く（Blender の入力欄には改行を入れられないため）
5. 置いたセリフ・立ち絵・表情ストリップを選ぶと、プロパティエディターの「ストリップ」タブ（Blender のストリップの設定と同じ場所。
   ストリップ名のすぐ下）でテキスト・表情・パーツ・声・発音・抑揚・字幕の位置や大きさなどを変えて「再生成」できる。
   テキストは押すと「セリフを編集」のダイアログが開く（「字幕だけ変える」にすると音声は作り直さない）。
   出るのは選んでいるストリップだけ（選択を外すと出なくなる）。複数を選んでまとめて変える・AI で表情を割り当てるなどは、
   サイドバーの「選んだストリップ」から

キャラクター設定は .blend に保存されます。TOML への書き出し・読み込みもできます（形式は `examples/characters.toml`）。

セリフの音声は、.blend のフォルダの `tachie/`（アドオン設定で出力フォルダを指定すればそこ）に書き出します。
未保存の .blend では一時フォルダに書き出し、保存するときに .blend のフォルダの `tachie/` へ移します。
立ち絵の合成画像は全プロジェクトで使い回すキャッシュ（macOS は `~/Library/Caches/blender_tachie/cache`。Time Machine の対象外）に
置きます。消しても、別の Mac にプロジェクトを持っていっても、立ち絵は開いたときに作り直します。

## 立ち絵素材

| 種類 | 対応 |
|---|---|
| YMM4 の動く立ち絵（「眉」「目」「口」「髪」「顔色」「体」「他」「後」のフォルダ） | 対応。まばたき・口パクの連番（`パーツ名.0.png` など）、あいうえお口パク（`パーツ名.a.png` など）、`パーツ名.ini` の opacity、合成モードの通常と乗算 |
| YMM4 のシンプル立ち絵（画像を入れただけのフォルダ） | 対応。口を閉じた画像とセリフ中の画像を選ぶと、セリフの間は声の大きさで 2 枚を切り替える（まばたきは無し） |
| PSD 立ち絵（PSDToolKit 形式: `*` はフォルダ内で 1 つだけ表示、`!` は常に表示） | 対応。表情は表示するレイヤーで選ぶ。口パク・まばたきは PSD の隣の `<PSD 名>-ymm.json`（YMM4 の PSD 立ち絵素材マネージャーが作る設定、または下のコマンドで作る）を使う。合成モードは通常と乗算 |

仕様: [動く立ち絵素材の作り方](https://www.manjubox.net/ymm4/faq/立ち絵機能/動く立ち絵素材の作り方)、
[シンプル立ち絵素材の作り方](https://www.manjubox.net/ymm4/faq/立ち絵機能/シンプル立ち絵素材の作り方)

素材ごとの利用規約（Blender での使用可否など）は各自で確認してください。

### キャラクターを追加するときの初期値

次の順に重ねて初期値にします（上が優先）。

1. アドオン設定に保存した、キャラクターごとの初期値（全 .blend 共通。「立ち絵」タブのメニューから保存。キーは素材フォルダの名前）
2. 素材フォルダの `tachie.toml`（キャラクター設定の TOML と同じ形式で、キャラ名のテーブルなし。メニューから書き出せる）
3. 素材フォルダの `preset.ini`（YMM4 の表情プリセット。メニューの「YMM4 の表情プリセットを読み込む」でも読める）

YMM4 の表情プリセットは他1 = 左腕、他2 = 右腕の並びで作られているので、基本の表情もこの並びにしてください。

立ち絵の無いキャラクターは素材フォルダが無いので、アドオン設定にだけキャラ名で保存できます（声・字幕・音量・セリフの形）。
「立ち絵なしのキャラクターを追加」や YMM4 の読み込みで同じ名前のキャラクターを追加すると、その設定で始まります
（YMM4 の読み込みでは、YMM4 の設定の方が優先）。

### PSD 立ち絵の口パク設定

PSD 立ち絵の口パク・まばたきは、PSD の隣の `<PSD 名>-ymm.json`（YMM4 と同じ設定ファイル）から読みます。
無い場合は、動く立ち絵の素材と、同じキャラクターの PSD 立ち絵から作れます（このアドオンと YMM4 の両方で使えます）。動く立ち絵の連番と同じ画像のパーツを探して、PSD のレイヤーに当てはめます。

```
uv run python -m tachie_studio.tachie.psd_animation <動く立ち絵の素材フォルダ> <PSD> [--dry-run]
```

既にある設定ファイルの表情プリセットは残します。

### AI で表情を割り当てる
1. LLM を用意する。OpenAI 互換のチャット API なら何でもよい（アドオン設定の「表情の割り当て（AI）」に入れる）

   | | 接続先の例 | 備考 |
   |---|---|---|
   | LM Studio | `http://127.0.0.1:1234` | サーバ機能を有効にする |
   | Ollama | `http://127.0.0.1:11434` | |
   | Apple Intelligence（[apfel](https://github.com/Arthur-Ficial/apfel)） | `http://127.0.0.1:11434` | macOS 26 以降。`brew install apfel` → `apfel --serve`。モデルは `apple-foundationmodel`。Mac の中で動く。常駐させるなら `brew services start apfel`（Ollama と同じポートなので同時には使えない）。番号の選択肢を受け付けないので、表情の名前で選ばせる |
   | Gemini | `https://generativelanguage.googleapis.com/v1beta/openai/` | API キーが要る。モデル名は `models/` から始まる。reasoning_effort は空に |

   「接続テスト」でモデルの一覧が出れば繋がっています（モデル名が空なら一覧の先頭が入ります）。
   ローカルの LLM なら台本は外に出ません。クラウドの API を使うと、選んだセリフと前後のセリフがそのサービスへ送られます。
2. セリフを選び、サイドバーの「選んだストリップ」の「AI で表情を割り当てる」を押す（Esc で取り消し）。書き込み先は次のどちらか
   - **セリフの表情**（既定）: セリフの表情プリセットを変える。音声は合成し直さない
   - **表情ストリップ**: セリフの区間に表情ストリップを置く（後から目で見て直しやすい）
3. 結果はテキストエディタの「表情の割り当て結果」に出る。LLM が「どれも合わない」と答えた行は変えない。
   元に戻すのは Ctrl+Z 1 回

精度は表情プリセットの名前でほぼ決まります（LLM は名前だけを見て選ぶため）。
- 「笑顔」「怒り」「悲しみ」「驚き」「照れ」「困惑」のような、感情を表す一般的な語にする。擬音（「ぬーん」）や番号だけの違い（「考える2」）は避ける
- ポーズだけのプリセット（「指差し」「食べる」）を混ぜない（怒りの行に「指差し」を選ぶことがある）
- 「基本の表情」（プリセット無し）も候補に入ります

API キーはアドオン設定（userpref.blend）に平文で残ります。残したくなければ環境変数 `TACHIE_LLM_API_KEY` に入れてください（こちらが優先）。

## 必要なもの

- Blender 5.2 以降
- VOICEVOX エンジン（既定は `http://127.0.0.1:50021`、アドオン設定で変えられる）、または VOICEVOX 互換のエンジン
  - AivisSpeech（`http://127.0.0.1:10101`）は、モーラの長さ・音高を返さないので、口パクは音量式になり、抑揚の編集は効きません。
    間の長さは無視され、声の高さを 0 から変えると音質が落ちることがあります（AivisSpeech Engine の仕様）
- 開発: [uv](https://docs.astral.sh/uv/)

## インストール

GitHub のリリースから、使う OS 用の zip（`blender_tachie-<version>-<OS>.zip`）を取ってきて、Blender の
「Install from Disk」で入れます。手元でビルドするときは:

```
uv run python scripts/build_addon.py --install
```

OS ごとの zip（`dist/blender_tachie-<version>-<OS>.zip`、その OS 用の Pillow と Brotli を同梱）を作り、`--install` ではこの OS 用を Blender に入れます。
他の OS では、その OS 用の zip を Blender の「Install from Disk」で入れてください。
Blender は環境変数 `BLENDER`、PATH の `blender`、標準のインストール先の順で探します。

Windows で立ち絵素材の zip（ファイル名が Shift_JIS のもの）を展開するときは、エクスプローラーの「すべて展開」か
Windows PowerShell 5.1 の `Expand-Archive` を使ってください。PowerShell 7 の `Expand-Archive` ではファイル名が化けます。

## コマンドライン

```
uv run python -m tachie_studio.tachie <素材フォルダ> --list                  # パーツ一覧
uv run python -m tachie_studio.lipsync "こんにちは" --speaker 3 -o out/line  # wav と口パクの JSON
uv run python -m tachie_studio.pipeline examples/script.txt -c examples/characters.toml -o out/demo
```

最後のコマンドは、台本からセリフごとの wav と口パク入りの透明連番画像を書き出します（他の動画編集ソフト用）。
`--srt` を付けると、セリフを順に（`--gap` 秒あけて）並べたときの字幕を `subtitles.srt` にも書き出します。
キャラクター設定に無い項目は素材フォルダの `tachie.toml` と `preset.ini` から補います。

## 開発

```
uv sync
uv run pytest
scripts/smoke.sh   # Blender での結合テスト（VOICEVOX エンジンと char/ の素材が必要。Windows では Git Bash で）
```

エンジンが別のマシンなら `VOICEVOX_URL=http://<host>:50021 scripts/smoke.sh`。音声デバイスの無い環境では試聴が警告になるだけで通ります。
