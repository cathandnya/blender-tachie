# blender-tachie

Blender 用の立ち絵アドオンです。VOICEVOX の音声に合わせて口パク・まばたきする立ち絵と字幕を、
Video Sequencer に並べます。YMM4 の「動く立ち絵」「シンプル立ち絵」「PSD 立ち絵」の素材と、表情プリセットも読み込めます。

## できること

### セリフを置く
- セリフを入力すると、音声・口パクする立ち絵・字幕の 3 本を再生位置に置く
- 台本（1 行に `キャラ名: セリフ`、表情は `キャラ名(困り): セリフ`）を一括で流し込む
- セリフの修正と再生成。長さが変わったら後ろのストリップをずらす
- 喋っていないキャラクターは、まばたきだけする待機の立ち絵で埋める。セリフなしの立ち絵も置ける
- 複数のセリフを選んで、表情・声・音量などをまとめて変える
- 別のキャラクターのセリフは時間を重ねて置ける（同時に喋る）。重なったセリフの音声・字幕・キャラ名は上の空いたチャンネルに置く。
  同じキャラクターのセリフは立ち絵が 1 つなので重ねられない
- セリフの形は「立ち絵あり」「音声と字幕」「音声だけ」。キャラクターごとの既定値と、置いたセリフごと（パネル・まとめて変える）に選べる。
  立ち絵の無い形で喋っている間は、そのキャラクターの立ち絵（待機）を消す
- 立ち絵の無いキャラクター（ナレーションなど、声と字幕だけ）も追加できる（キャラクター設定のメニュー）

### 表情
- キャラクターごとの基本の表情と表情プリセット。他・後（腕や記号）はスロットごとに置き換える（YMM4 と同じ）
- 表情ストリップ: タイムラインに置いた範囲だけ表情を変える。セリフの途中からでも、音声はそのまま
  （動かしたり伸ばしたりすると自動で描き直す）

### 立ち絵の動き
- 喋っている間に跳ねる（上下）・揺れる（左右に傾く）。高さ・角度・速さはキャラクターごと
- 登場・退場（フェード、近い方の画面の端からスライド）。キャラの立ち絵が現れる・消えるところに自動で付く
- セリフ（立ち絵）ごとの位置・大きさ（足元を中心に拡大）
- 置いてある立ち絵にすぐ反映する（立ち絵ストリップの位置・回転・不透明度のキーフレーム）
- 立ち絵ストリップの位置・大きさ・回転・不透明度はアドオンが管理するので、パネルで変える
  （Blender のストリップ設定で直接変えても、セリフの追加などで元に戻る）

### 声（YMM4 のボイスアイテム相当）
- キャラクターごとに声のエンジンを選べる（VOICEVOX と同じ API の AivisSpeech・SHAREVOX・COEIROINK v1、または URL を指定）
- セリフごとにキャラクター・スタイル・読み上げ速度・声の高さ・抑揚・合成の音量・開始/終了無音・間の長さを変える
- 発音（読み・アクセント）の編集と試聴。台本では `セリフ{キョ'ウワ/イ'イ/テ'ンキ}`
- 抑揚の編集: モーラごとの音高、子音・母音の長さ、句全体の高さ、試聴
- VOICEVOX のユーザー辞書の登録・削除
- 音量・パン（すぐ反映）、フェードイン/アウト・セリフ後の余韻

### 口パク・字幕
- 口パクはあいうえお式（音素の母音）と音量式
- 字幕のフォント・大きさ・色・縁取り・高さ・背景の帯（色・余白・角の丸み）はキャラクターごと。変えると置いてある字幕にすぐ反映する
- 字幕の上にキャラ名（縁取りの色の帯）を出す、字幕のフェードイン
- セリフごとに字幕（とキャラ名）の位置をずらせる（同時に喋るセリフの字幕が重なるときなど。重なると置いたときに知らせる）
- 見出しテロップ（話題の切り替えに出す大きめの文字。スタイルはシーンで共通で、変えるとすぐ反映）
- 立ち位置・左右反転もキャラクターごとで、すぐ反映する
- 「書き出し」パネル: 動画の書き出し設定のプリセット（1080p / 60fps / 720p / 4K / 縦長、MP4・H.264・AAC）、
  字幕を SRT / WebVTT で書き出す（YouTube などの字幕用）

### BGM
- 選んだ音声ストリップを BGM にすると、セリフの音声が鳴っている間だけ自動で音量を下げる（ダッキング）。
  下げる割合と、下げる・戻す時間を選べる。セリフを追加・移動すると作り直す
- BGM の音量はアドオンが管理するので（音量のキーフレーム）、「BGM」パネルで変える

### 効果音
- よく使う効果音を登録しておき（アドオン設定、全 .blend 共通。音量も登録できる）、「効果音」パネルのボタンで置く
- 置く場所は再生位置か、選んでいるセリフそれぞれの頭

### テンプレート
- 選んだストリップ（セリフ・表情・画像・動画・音声・テキスト・カラー）を名前を付けて登録し、「テンプレート」パネルのボタンで
  再生位置に置く（YMM4 のテンプレートと同じ使い方）。アドオン設定に保存するので、どの .blend でも使える
- セリフは置くときに合成し直す（キャラ・テキスト・表情・声・発音・抑揚・形を持つ）。キャラは名前で探す
- 「立ち絵より奥に置く」にしたテンプレート（背景など）は、画像・動画・カラーをアドオンのチャンネルより下に置く
- YMM4 のテンプレート（`user/setting/<版>/YukkuriMovieMaker.Settings.ItemSettings.json`）を読み込める。
  ボイス・表情・画像・動画・音声・テキストを取り込み、立ち絵アイテム・トランジション・図形・エフェクトは読まない

### YMM4 のプロジェクトの読み込み
- 「台本の流し込み」パネルの「YMM4 のプロジェクトを読み込む」で、.ymmp のキャラクター・セリフ・表情を読み込む
  - セリフは YMM4 に保存された発音・抑揚・話速などで VOICEVOX から合成し直す（同じ位置に置く）
  - 無いキャラクターは「素材フォルダを探す場所」から YMM4 と同じ名前の素材フォルダを探して追加し、声・字幕・立ち位置・基本の表情を写す
  - YMM4 で立ち絵の無いキャラクターは、立ち絵の無いキャラクターとして追加し、セリフは音声と字幕（字幕を出さないなら音声だけ）で置く
  - ボイスアイテムの表情と表情アイテムは、表情プリセット（足りなければ作る）と表情ストリップにする
- 画像・動画・音声・テキストのアイテムも、位置・大きさ・回転・不透明度・音量・再生速度・切り取り位置・直線移動の
  アニメーションごと置く（ダイアログで切れる）
  - ファイルは元のパス → .ymmp と同じフォルダ → その下 → 「画像・動画などを探す場所」の順に、同じ名前で探す
  - 立ち絵より奥のレイヤーの画像・動画は、アドオンのチャンネル（音声・立ち絵・字幕など）を上へずらして、その下に置く
  - 動画は素材のフレームレートと再生速度に合わせるため、スピードコントロールのストリップを重ねることがある
  - BGM はアドオンの BGM（ダッキング）にはしない（YMM4 の音量のまま。使うなら「BGM にする」）
- トランジション・図形・エフェクトのアイテムと、映像エフェクト（縁取り・影・ぼかしなど）は読み込まない。
  読み込まなかったもの・見つからなかったファイル・写せなかった設定は、テキストエディタの「YMM4 の読み込み結果」にまとめる
- YMM4 の音量 50 を等倍として写す

### コマンドライン
- 立ち絵の合成と口パクの計算は Blender に依存しない Python モジュールで、台本から wav と透明連番画像を書き出せる

## 使い方

1. Video Sequencer のサイドバー（N キー）の「立ち絵」タブを開く
2. ＋ で素材フォルダ（PSD 立ち絵なら PSD ファイル）を選んでキャラクターを追加し、キャラクター設定で話者（VOICEVOX のスタイル）や表情を選ぶ
3. セリフを入力して「〇〇のセリフを追加」、または「台本の流し込み」でまとめて置く
4. 置いたセリフを選ぶと、「選択中のセリフ」でテキスト・表情・声・発音・抑揚などを変えて「再生成」できる

キャラクター設定は .blend に保存されます。TOML への書き出し・読み込みもできます（形式は `examples/characters.toml`）。

## 立ち絵素材

| 種類 | 対応 |
|---|---|
| YMM4 の動く立ち絵（「眉」「目」「口」「髪」「顔色」「体」「他」「後」のフォルダ） | 対応。まばたき・口パクの連番（`パーツ名.0.png` など）、あいうえお口パク（`パーツ名.a.png` など）、`パーツ名.ini` の opacity、合成モードの通常と乗算 |
| YMM4 のシンプル立ち絵（画像を入れただけのフォルダ） | 対応。口を閉じた画像とセリフ中の画像を選ぶと、セリフの間は声の大きさで 2 枚を切り替える（まばたきは無し） |
| PSD 立ち絵（PSDToolKit 形式: `*` はフォルダ内で 1 つだけ表示、`!` は常に表示） | 対応。表情は表示するレイヤーで選ぶ。口パク・まばたきは PSD の隣の `<PSD 名>-ymm.json`（YMM4 の PSD 立ち絵素材マネージャーが作る設定、または下のコマンドで作る）を使う。合成モードは通常と乗算 |

仕様: [動く立ち絵素材の作り方](https://www.manjubox.net/ymm4/faq/立ち絵機能/動く立ち絵素材の作り方)、
[シンプル立ち絵素材の作り方](https://www.manjubox.net/ymm4/faq/立ち絵機能/シンプル立ち絵素材の作り方)

素材ごとの利用規約（Blender での使用可否など）は各自で確認してください。

### キャラクターを追加するときの初期値

次の順に重ねて初期値にします（上が優先）。

1. アドオン設定に保存した、キャラクターごとの初期値（全 .blend 共通。「立ち絵」タブのメニューから保存）
2. 素材フォルダの `tachie.toml`（キャラクター設定の TOML と同じ形式で、キャラ名のテーブルなし。メニューから書き出せる）
3. 素材フォルダの `preset.ini`（YMM4 の表情プリセット。メニューの「YMM4 の表情プリセットを読み込む」でも読める）

YMM4 の表情プリセットは他1 = 左腕、他2 = 右腕の並びで作られているので、基本の表情もこの並びにしてください。

### PSD 立ち絵の口パク設定

PSD 立ち絵の口パク・まばたきは、PSD の隣の `<PSD 名>-ymm.json`（YMM4 と同じ設定ファイル）から読みます。
無い場合は、動く立ち絵の素材と、同じキャラクターの PSD 立ち絵から作れます（このアドオンと YMM4 の両方で使えます）。動く立ち絵の連番と同じ画像のパーツを探して、PSD のレイヤーに当てはめます。

```
uv run python -m tachie_studio.tachie.psd_animation <動く立ち絵の素材フォルダ> <PSD> [--dry-run]
```

既にある設定ファイルの表情プリセットは残します。

## 必要なもの

- Blender 5.2 以降
- VOICEVOX エンジン（既定は `http://127.0.0.1:50021`、アドオン設定で変えられる）、または VOICEVOX 互換のエンジン
  - AivisSpeech（`http://127.0.0.1:10101`）は、モーラの長さ・音高を返さないので、口パクは音量式になり、抑揚の編集は効きません。
    間の長さは無視され、声の高さを 0 から変えると音質が落ちることがあります（AivisSpeech Engine の仕様）
- 開発: [uv](https://docs.astral.sh/uv/)

| OS | 状態 |
|---|---|
| macOS（Apple Silicon） | 確認済み |
| Windows（x64） | 確認済み（Windows 11。インストール・セリフの追加・台本の流し込み・結合テスト） |
| Linux（x64） | 確認済み（画面なしの Ubuntu で結合テストが通る） |
| Windows（ARM）・macOS（Intel） | zip はビルドするが未確認 |

## インストール

GitHub のリリースから、使う OS 用の zip（`blender_tachie-<version>-<OS>.zip`）を取ってきて、Blender の
「Install from Disk」で入れます。手元でビルドするときは:

```
uv run python scripts/build_addon.py --install
```

OS ごとの zip（`dist/blender_tachie-<version>-<OS>.zip`、その OS 用の Pillow を同梱）を作り、`--install` ではこの OS 用を Blender に入れます。
他の OS では、その OS 用の zip を Blender の「Install from Disk」で入れてください。
Blender は環境変数 `BLENDER`、PATH の `blender`、標準のインストール先の順で探します。

Windows で立ち絵素材の zip（ファイル名が Shift_JIS のもの）を展開するときは、エクスプローラーの「すべて展開」か
Windows PowerShell 5.1 の `Expand-Archive` を使ってください。PowerShell 7 の `Expand-Archive` ではファイル名が化けます。

## コマンドライン

```
uv run python -m tachie_studio.tachie <素材フォルダ> --list                  # パーツ一覧
uv run python -m tachie_studio.lipsync "こんにちは" --speaker 3 -o out/line  # wav と口パクの JSON
uv run python -m tachie_studio.pipeline examples/script.txt -c examples/characters.toml -o out/demo
```

最後のコマンドは、台本からセリフごとの wav と口パク入りの透明連番画像を書き出します（他の動画編集ソフト用）。
`--srt` を付けると、セリフを順に（`--gap` 秒あけて）並べたときの字幕を `subtitles.srt` にも書き出します。
キャラクター設定に無い項目は素材フォルダの `tachie.toml` と `preset.ini` から補います。

## 開発

```
uv sync
uv run pytest
scripts/smoke.sh   # Blender での結合テスト（VOICEVOX エンジンと char/ の素材が必要。Windows では Git Bash で）
```

エンジンが別のマシンなら `VOICEVOX_URL=http://<host>:50021 scripts/smoke.sh`。音声デバイスの無い環境では試聴が警告になるだけで通ります。
